SITE DA AEFOS — como publicar (gratuito)

Conteúdo desta pasta:
  index.html        -> página principal (Início, Sobre, Notícias, Documentos)
  dashboard.html    -> painel de dados (abre a partir do site)
  assets/           -> logo e favicon

COMO COLOCAR NO AR (Netlify, grátis, sem código):
  1. Acesse app.netlify.com/drop
  2. Arraste ESTA PASTA inteira (aefos_site) para a área indicada
  3. Pronto: você recebe um link tipo https://aefos.netlify.app
  4. Para usar seu domínio próprio: Site settings -> Domain management -> Add domain

Alternativas gratuitas: Cloudflare Pages, GitHub Pages.

Para atualizar (notícias, estatuto, etc.): peça ao Claude ou edite os arquivos .html
(as notícias ficam na seção <!-- NOTÍCIAS --> do index.html).
